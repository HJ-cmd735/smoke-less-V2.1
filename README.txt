SmokeLess TW V2.1 Safari 修正版

修正：
- iPhone Safari / PWA 按鈕無反應
- 全部按鈕改用 addEventListener
- 不再依賴 HTML id 自動建立 JS 變數
- 保留 V2.0 的 localStorage key，因此既有資料可延續
- 更新 Service Worker 快取版本
- 修正 JSON 匯入

更新方式：
1. 解壓縮 ZIP。
2. 把 6 個檔案覆蓋 GitHub repository 根目錄原檔。
3. Commit changes。
4. iPhone 刪除舊主畫面 SmokeLess。
5. Safari 開啟 https://hj-cmd735.github.io/smoke-less-V2.0/
6. 重新整理並測試按鈕。
7. 分享 > 加入主畫面。
